## 1. `match/case`：结构化模式匹配

### 1.1 基础语法

Python 3.10 引入 `match/case`。它可以匹配常量，也可以解构序列、字典和对象，再将匹配出的值绑定到变量。因此它更接近“模式匹配”，不只是其他语言中按值分支的 `switch`。

```python
def describe_status(status: int) -> str:
    match status:
        case 200:
            return "成功"
        case 404:
            return "未找到"
        case 500:
            return "服务器错误"
        case _:
            return "未知状态"
```

`_` 是通配模式，表示“其他所有情况”。通常放在最后。

### 1.2 支持或模式

```python
match command:
    case "quit" | "exit":
        print("退出")
    case "help" | "?":
        print("显示帮助")
```

或模式两边绑定的变量必须一致，否则语法无效。

## 2. 联合类型：`X | Y`

### 2.1 基础语法

Python 3.10 引入 PEP 604。类型注解中的 `|` 表示一个值可以属于多个类型。

```python
def parse_id(value: str | int) -> int:
    return int(value)


def find_user(user_id: int) -> str | None:
    if user_id == 1:
        return "小明"
    return None
```

### 2.2 与 `isinstance()` 一起用

在 Python 3.10+，普通类组成的联合类型可以用于 `isinstance()`：

```python
value = "42"
print(isinstance(value, int | str))  # True
```
