## 1。 延期求值注解与`annotationlib`

Python 的类型注解过去常在定义函数或类时立即计算。这会导致前向引用、循环导入和昂贵注解计算更麻烦。

Python 3.14 采用延迟（deferred / lazy）求值模型：注解会在真正需要时再被计算。这样可以自然引用稍后定义的类型，并减少仅为类型提示而产生的导入问题。

### 1.1 基础语法

```python
import annotationlib


def create_user(name: str, age: int) -> dict[str, str | int]:
    return {"name": name, "age": age}

annotations = annotationlib.get_annotations(create_user)
print(annotations)  # 输出结果: {'name': <class 'str'>, 'age': <class 'int'>, 'return': dict[str, str | int]}
```

### 1.2 三种读取格式

`annotationlib.Format` 用于控制注解读取方式。实际框架开发常见的三个概念是：

- `VALUE`：尽可能得到正常的已求值类型对象；日常运行时反射通常使用它。
- `FORWARDREF`：无法立即解析的名称保留为前向引用对象，适合复杂循环引用场景。
- `STRING`：保留字符串形式，适合文档生成、静态分析或不希望触发求值的工具。

```python
import annotationlib

hints = annotationlib.get_annotations(
    create_user,
    format=annotationlib.Format.VALUE,
)
print(hints["name"])    # 输出: <class 'str'>
```

## 2. `compression.zstd`：标准库 Zstandard 压缩

Python 3.14 增加 `compression.zstd`，为 Zstandard（Zstd）压缩（无损实时数据压缩）提供标准库支持。Zstd 常用于需要兼顾压缩率与速度的日志、缓存、数据传输和归档场景。

### 2.1 基础语法

```python
from compression import zstd

raw = b"Python 3.14 " * 10_000
compressed = zstd.compress(raw)
restored = zstd.decompress(compressed)

assert restored == raw
print(f"原始：{len(raw)}，压缩后：{len(compressed)}")   # 输出: 原始：120000，压缩后：32
```

### 2.2 文件流

对大文件不应把全部内容一次读进内存。可使用流式压缩/解压 API：

压缩:

```python
from compression import zstd

with open("input.log", "rb") as source:
    with open("output.log.zst", "wb") as target:
        with zstd.open(target, "wb") as compressed_file:
            while chunk := source.read(1024 * 1024):
                compressed_file.write(chunk)
```

解压:

```python
from compression import zstd

with open("output.log.zst", "rb") as source:
    with zstd.open(source, "rb") as decompressed_file:
        while chunk := decompressed_file.read(1024 * 1024):
            process(chunk)
```

### 2.3 特殊说明

- 压缩不是加密；敏感数据仍需要加密、访问控制和密钥管理。
- 对不可信压缩文件应设置解压大小、时间和资源限制，防止压缩炸弹导致内存或磁盘耗尽。
- 若需兼容旧 Python，可使用第三方 `zstandard` 包，并将压缩实现封装在独立模块。
