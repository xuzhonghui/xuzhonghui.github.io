> TOML 常用于项目配置，例如 `pyproject.toml`。Python 3.11 新增标准库 `tomllib`，不再需要仅为读取 TOML 安装第三方库。

## 1 解析文件

```python
import tomllib

with open("pyproject.toml", "rb") as file:
    config = tomllib.load(file)

print(config["project"]["name"])
```

## 2 解析字符串

```python
import tomllib

content = b'''\
[server]
host = "127.0.0.1"
port = 8080
'''
config = tomllib.loads(content.decode("utf-8"))
print(config["server"]["port"])
```

## 3 重要限制

- `tomllib` 只读，不提供 TOML 写入功能。
- `load()` 需要以二进制模式打开文件，即 `"rb"`。
- 解析不可信或错误配置时应处理 `tomllib.TOMLDecodeError`。

```python
import tomllib

try:
    with open("config.toml", "rb") as file:
        config = tomllib.load(file)
except FileNotFoundError:
    config = {}
except tomllib.TOMLDecodeError as error:
    raise RuntimeError("配置文件格式错误") from error
```

若需要兼容 Python 3.10 及以下，可依赖第三方 `tomli`；它的 API 与 `tomllib` 基本一致。
